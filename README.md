# Wedding studio demo

Next.js (App Router) + Tailwind CSS v4 + TypeScript.

## Run

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Where things live

- `lib/content.ts` — studio name, copy, image URLs (placeholders from picsum.photos; needs internet)
- `components/Hero.tsx` — hero section
- `components/ImageGrid.tsx` — image grid (effect goes here)
- `components/Portfolio.tsx` — portfolio section
- `app/globals.css` — colour and font tokens (`@theme`)
